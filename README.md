<h1 align="center">XEON AIO</h1>

<p align="center">All-in-one Discord bot built with Python and discord.py. Moderation, security, tickets, giveaways and more, in Components V2.</p>

---

## Features

<table>
<tr>
<td width="33%" valign="top">

**Security**

- Antinuke with wizard and filters
- Whitelist and extra owners
- AutoMod with whitelist and blacklist
- Moderation commands
- Purge tools
- Logging

</td>
<td width="33%" valign="top">

**Community**

- Ticket system
- Giveaways
- Welcome / greet system
- Message and invite tracker
- Reaction roles
- Autorole
- AutoResponder and AutoReact

</td>
<td width="33%" valign="top">

**Management**

- Embed builder
- User, server, role and channel info
- List commands
- Per-server prefix and ignored channels
- NoPrefix and premium system
- SQLite database
- `.env` configuration

</td>
</tr>
</table>

## Setup

<table>
<tr>
<td><b>1. Clone</b></td>
<td>

```bash
git clone https://github.com/r3novadcl/XEON-AIO.git
cd XEON-AIO
```

</td>
</tr>
<tr>
<td><b>2. Install</b></td>
<td>

```bash
pip install -r requirements.txt
```

</td>
</tr>
<tr>
<td><b>3. Configure</b></td>
<td>

Copy `.env.example` to `.env` and fill it in:

```env
DISCORD_TOKEN=YOUR_BOT_TOKEN
CLIENT_ID=YOUR_APPLICATION_ID
OWNER_IDS=YOUR_DISCORD_ID
```

</td>
</tr>
<tr>
<td><b>4. Run</b></td>
<td>

```bash
python main.py
```

</td>
</tr>
</table>

On first start the bot uploads its emojis to your application automatically.
